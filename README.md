# EchoVibe 🚀

EchoVibe is a smart, AI-powered content generation engine that creates high-quality, brand-aligned social media posts based on campaign ideas and business profiles.

## 💡 What It Does

EchoVibe helps businesses and creators:

- Define campaign tone, target audience, and topic
- Generate unique campaign ideas
- Convert selected ideas into engaging social media posts
- Suggest image/video media prompts, voiceovers, and hashtags
- Ensure brand consistency by filtering against business profile

## 🛠 Tech Stack

- **Python** & **FastAPI** – backend API framework
- **Pydantic** – for request validation and schema management
- **SQLAlchemy** – ORM for database interaction
- **SQLite/PostgreSQL** – database options
- **OpenAI / LLM** – for natural language generation (optional integration)
